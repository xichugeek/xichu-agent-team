# 隐私边界

- 公开配置的本人/群 ID 为0，Token示例为空。真实值放被忽略的 `config.local.json`、`secrets.local.json`。
- 不提交 Codex auth/config、账号目录、SSH密钥/密码、环境文件、数据库、聊天历史、回执、模型日志、备份、声音参考/特征或私人素材。
- 看板不读 Telegram secrets，只读公开/本地覆盖配置元数据和只读工单库。身份/额度仅在本机页面显示。
- 服务只绑定loopback，不直接开放公网；重置接口要求严格同源、页面令牌及本人确认。
- 历史工具仅查询该阶段授权的同本人/同群快照，不接收任意路径，校验哈希并分页限长；摘要不授予权限。
- 提交前检查实际暂存区。`.gitignore` 不能阻止已跟踪文件泄露，不把运行目录当源码上传。
- 输出自己的日志/截图需另行脱敏；本仓库不附作者的运行截图或生产回执。测试信息均为合成数据。

代码不赋予第三方账号或机器访问权。服务器和发布操作以本人具体授权为准。
