# 从旧版升级

v0.2.0 的默认岗位改为 Codex 项目经理、视频制作、官网运维，配置和阶段名称有变化。

1. 停止旧版，备份自己的配置和运行目录，备份不提交 Git。
2. 在新目录克隆/解压新版，保留旧版查看历史。旧 `writer/coder/work` 工单并非新制作流程，不要直接恢复其未完成阶段。
3. 用新示例创建 `config.local.json`、`secrets.local.json`，填自己的机器人、ID、账号和工作区。
4. 先运行 doctor，再启动。单账号可先用，B/C 按需独立登录后启用。

`python -m agent_team` 保留为新版 CLI 兼容入口，新源码位于 `xichu_agent/`。旧视频固定提交 `98548e5` 仍可访问。

默认不自动追加 AI 审核；原项目必要人工关卡保留，不从旧聊天补签。
