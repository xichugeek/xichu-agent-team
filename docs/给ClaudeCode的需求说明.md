# 给 Claude Code 的需求说明

想要不一样的岗位（客服、周报、盯服务器……），把下面这段复制给 Claude Code，把【】里的内容换成你自己的。在本模板目录里运行 Claude Code，它会在模板基础上改；没有模板也能让它从头写。

```
我想在自己的 Windows 电脑上搭一个“AI 员工团队”，在 Telegram 私人群里派活。请在当前目录的模板基础上帮我改成我自己的岗位（没有模板就从头写）：

1. 群里有 3 个机器人：项目经理(Claude Code)、【岗位 1】(Codex)、【岗位 2】(Codex)。
   - 【岗位 1】负责：【写清楚它做什么、交付什么、放在哪个目录】
   - 【岗位 2】负责：【同上】
2. 我在群里 @项目经理 说需求，它判断派给谁，不清楚就只问我一个问题；@某个员工就直接交给它。
3. 员工做完后，项目经理做一次独立质检，不合格退回返工一轮，结果回复在我原来那条消息下面。
4. 只认我本人（Telegram 用户 ID）在这个群里的消息；私聊、别的群、别人一律不执行。
5. 只用 Claude Code 和 Codex 的订阅登录，启动子进程前去掉 OPENAI_API_KEY、ANTHROPIC_API_KEY，不是订阅登录就拒绝执行。
6. 默认只写本地工作目录；发布、上传、付款、删除、改服务器之类的操作一律不做，交给我自己确认。
7. 工单存本地 SQLite，重启后能接着做；同一条消息不重复执行；额度受限时排队并告诉我大约几点恢复。
8. 提供 doctor 自检、启动/停止脚本和自动化测试，测试全部通过后告诉我怎么配置 Telegram 机器人。
```
