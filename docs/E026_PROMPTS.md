# 第026期可复制教学提示词

以下是整理后的教学示例，不是历史原始聊天记录。先下载v0.2.1源码，再把适用的一段发给自己的Codex。每一步以真实结果验收，不上传凭据或音色参考。

## 1. 从教学Demo检查环境

```text
请读取当前仓库README和docs/QUICKSTART_E026.md。我的目标是先在自己的Windows电脑运行v0.2.1教学看板，不连接Telegram、不调用Codex账号和生产数据库。检查Python后运行demo_dashboard.py，验证总览、工单、额度、制作、官网五个页面及教学标识。只报告实际访问和检查结果；不要改系统代理、网络或安装不必要的软件。缺少环境就说明具体缺项。
```

## 2. 单账号跑通真实工单

```text
请先读README、docs/ACCOUNTS.md、配置示例和当前代码。我要用一个自己的已登录Codex账号，跑通本人Telegram私群的接单、执行和回群。检查现有环境后指导创建config.local.json及secrets.local.json，Token和真实ID只保留本机，不输出登录文件内容，不修改系统代理。运行doctor并解决实际缺项，用一张不会上传发布或访问生产服务器的小任务验收。交付同一工单号、真实本地产物和看板记录，不把合成执行当真实执行。
```

## 3. 接入自己的视频或官网工作区

```text
我要将自己已有的视频制作或网站维护工作区接入v0.2.1。先读取那个工作区的AGENTS.md、技能、工具和状态，再做本地适配，复用已有能力和素材。明确哪些操作已经实测、哪些仍缺工具或权限；不要使用作者的声纹、服务器配置或账号，不上传我的凭据或声音参考。不得以合成测试冒充正式交付，人工审片和发布仍由本人确认。完成后给出实际产物、验证结果和可在原工单接续的未完成事项。
```

## 4. 配置同局域网手机只读查看

```text
请读取docs/CONTROL_CENTER.md并检查本机正在连接局域网的接口，仅做只读网络信息查询。使用v0.2.1的--enable-lan参数配置我实际IPv4/子网前缀，访问密码只留本机，保留默认仅本机的可恢复配置。不要替我改代理、防火墙、网卡类别或公网端口转发。指导我在同一可信Wi-Fi的手机访问并验证登录、查看和刷新；远端不能拿到重置令牌或执行写操作。没有我的手机真实结果，不报告手机验收通过。
```

## 5. 按同一工单定位问题和接续

```text
我已有一张工单需要接续。请按该工单号读取事实摘要和必要历史，保留原记录、人工授权凭据和已完成产物。先区分本次请求是否完成、整期制作台账状态、实际工程能否打开，不把百分比当用时。遇失败只复查涉及的步骤；不重复重做已通过且输入未变的工作，不追加不必要的项目经理/审核循环。完成后回群说明实际结果、失败原因和下一步。
```
